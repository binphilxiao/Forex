🚀 快速启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Windows用户:      双击 "启动图形界面.bat"
  所有平台:         python start_gui.py
  直接运行:         python fxcm_gui.py


📋 主要功能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  📥 下载数据          从FXCM下载M1和D1原始数据
  🔄 转换数据          将M1转换为M5/M15/M30/H1
  📊 分析数据          检查完整性并生成报告
  ⏹  停止任务          终止正在运行的任务
  🗑  清空日志          清除界面日志显示


💡 使用流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  选择货币对和年份范围
  2️⃣  点击"下载数据"（首次使用）
  3️⃣  等待下载完成（2-4小时）
  4️⃣  点击"转换数据"
  5️⃣  等待转换完成（1-3小时）
  6️⃣  点击"分析数据"
  7️⃣  查看生成的HTML报告


⚡ 命令行替代方案
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  如果不想用GUI，可以直接运行脚本：

  python download_fxcm_candles.py         # 下载数据
  python convert_m1_to_multi_timeframes.py  # 转换数据
  python check_data_completeness.py       # 分析数据

🆘 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: GUI无法启动？
  A: 确保已安装Python 3.7+，tkinter通常随Python一起安装

  Q: 下载失败？
  A: 大量404错误是正常的，FXCM某些周次数据不存在

  Q: 转换失败？
  A: 确保已先下载M1数据

  Q: 在哪查看分析报告？
  A: 点击"打开日志目录"，找到最新的HTML文件
