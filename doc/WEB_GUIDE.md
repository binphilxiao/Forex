# FXCM Web界面使用指南 v4.1

## 🎉 全新Flask Web界面

### 最新更新 (v4.1.0)

✨ **数据分析可视化** - 分析完成自动打开可视化报告  
✨ **智能报告管理** - 报告文件自动追踪和打开  

### 为什么选择Flask版本？

✅ **轻量级** - 仅需Flask库，比Streamlit更简单  
✅ **友好界面** - 现代化设计，响应式布局  
✅ **实时更新** - Ajax自动刷新，无需手动刷新页面  
✅ **稳定可靠** - 无Streamlit的多线程问题  
✅ **移动友好** - 支持手机/平板访问

## 🎨 界面功能

### 左侧控制面板

#### 📊 状态显示
- **当前状态**: 显示任务运行状态
- **进度条**: 实时显示任务进度
- **进度百分比**: 数字显示进度

#### 🎮 操作按钮

**📥 下载数据**
- 功能: 从FXCM下载M1和D1原始数据
- 时间: 2-4小时（全量下载）
- 要求: 稳定网络连接

**🔄 转换数据**
- 功能: M1转换为M5/M15/M30/H1
- 时间: 1-3小时（全量转换）
- 要求: 已有M1数据

**📊 分析数据**
- 功能: 数据完整性检查
- 时间: 5-10分钟
- 输出: HTML可视化报告（自动打开）
- 特色: **完成后自动在新窗口打开报告**

**⏹ 停止任务**
- 功能: 终止正在运行的任务
- 说明: 仅在任务运行时显示

**🗑 清空日志**
- 功能: 清除界面显示的日志
- 说明: 不影响日志文件

#### 📂 快捷操作
- **📂 数据目录**: 打开fxcm_data文件夹
- **📄 日志目录**: 打开logs文件夹

### 右侧日志面板

#### 实时日志显示
- **彩色分级**: 不同类型消息不同颜色
  - 🔵 **蓝色** - 一般信息
  - 🟢 **绿色** - 成功消息
  - 🟡 **黄色** - 警告信息
  - 🔴 **红色** - 错误信息

- **自动滚动**: 新日志自动滚动到底部
- **时间戳**: 每条日志显示时间

## 🆘 故障排除

### 问题1: 浏览器无法访问

**错误**: "无法访问此网站"

**解决**:
1. 确认Flask服务器已启动
2. 检查防火墙设置
3. 尝试http://127.0.0.1:5000

### 问题2: 任务无响应

**现象**: 点击按钮无反应

**解决**:
1. 打开浏览器开发者工具(F12)
2. 查看Console标签是否有错误
3. 刷新页面重试

### 问题3: 日志不更新

**现象**: 日志窗口不显示新内容

**解决**:
1. 检查任务是否真的在运行
2. 查看logs目录的日志文件
3. 刷新浏览器页面

### 问题4: 中文乱码

**现象**: 日志显示乱码

**解决**:
- 这不应该发生，已有UTF-8编码修复
- 如果出现，请检查脚本是否最新版本

## 💻 高级功能

### 远程访问

让同事通过局域网访问：

```python
# flask_app.py已默认配置
app.run(host='0.0.0.0', port=5000)

# 同事访问: http://你的IP:5000
```

### 修改端口

```python
# 修改flask_app.py最后一行
app.run(host='0.0.0.0', port=8080)  # 改为8080
```

### 后台运行

Windows:
```bash
start /b python flask_app.py
```

Linux/Mac:
```bash
nohup python flask_app.py &
```
