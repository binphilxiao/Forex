# FXCM Web界面故障排除指南

## 问题：按钮显示为灰色无法点击

### 可能原因和解决方案：

#### 1. **依赖库问题**
**现象**: 所有按钮都是灰色，无法点击
**原因**: Streamlit或Plotly库未正确安装
**解决**: 
```bash
pip install streamlit plotly pandas requests
```

#### 2. **脚本文件缺失**
**现象**: 特定功能按钮灰色
**原因**: 对应的Python脚本文件不存在
**解决**: 确保以下文件存在于项目目录：
- `download_fxcm_candles.py` (数据下载)
- `convert_m1_to_multi_timeframes.py` (数据转换)  
- `check_data_completeness.py` (数据分析)

#### 3. **配置未选择**
**现象**: 按钮灰色且有警告信息
**原因**: 
- 数据下载：未选择货币对
- 数据转换：未选择货币对或目标时间周期
- 数据分析：没有数据文件
**解决**: 在侧边栏配置相应选项

#### 4. **数据依赖问题**
**现象**: 转换和分析按钮灰色
**原因**: 
- 数据转换需要M1数据存在
- 数据分析需要任意数据存在
**解决**: 先运行数据下载

## 推荐使用方式：

### 方式1：使用简化版界面（推荐）
```bash
streamlit run fxcm_web_interface_simple.py
```

### 方式2：使用启动脚本
```bash
python run_web_interface.py
```
选择"简化版"

### 方式3：使用演示脚本
```bash
python demo_setup.py
```

## 简化版 vs 完整版界面：

| 特性 | 简化版 | 完整版 |
|------|--------|--------|
| 依赖要求 | 仅需streamlit和plotly | 需要导入所有模块 |
| 启动速度 | 快 | 较慢 |
| 功能完整性 | 基础功能完整 | 高级功能更多 |
| 稳定性 | 高 | 依赖模块导入 |
| 推荐场景 | 新用户、演示 | 高级用户 |

## 使用流程：

1. **检查环境**: 确认Python和依赖库已安装
2. **启动界面**: 使用简化版界面
3. **配置选项**: 在侧边栏选择货币对和时间范围  
4. **下载数据**: 点击"开始下载"
5. **转换数据**: 有M1数据后，点击"开始转换"
6. **分析数据**: 点击"分析数据"查看报告

## 常见错误信息：

- **"❌ 下载脚本不存在"**: 缺少download_fxcm_candles.py文件
- **"❌ 转换脚本不存在"**: 缺少convert_m1_to_multi_timeframes.py文件  
- **"❌ 分析脚本不存在"**: 缺少check_data_completeness.py文件
- **"⚠️ 请先选择要下载的货币对"**: 在侧边栏选择货币对
- **"⚠️ 未发现M1数据"**: 需要先下载M1数据才能转换
- **"🔄 有任务正在运行"**: 等待当前任务完成

## 技术支持：

如果仍然无法解决问题：
1. 检查"系统状态"标签页查看详细信息
2. 查看最新日志文件了解错误详情
3. 确认所有脚本文件完整且可执行
4. 重新安装依赖库: `pip install -r requirements.txt`
