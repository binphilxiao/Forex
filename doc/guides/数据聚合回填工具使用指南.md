# ClickHouse 数据聚合回填工具使用指南

## 📊 功能概述

`backfill_aggregated_data.py` 是一个灵活的数据聚合回填工具，可以从 M1 数据自动生成 M5、M15、M30、H1 时间周期的数据。

### 主要特性

✅ **灵活选择**
- 选择特定货币对
- 选择特定时间周期
- 选择特定时间段

✅ **两种回填模式**
- **增量回填**（默认）：只填补缺失的数据
- **全量回填**：删除现有数据并重新聚合

✅ **智能处理**
- 自动检测缺失数据
- 避免重复聚合
- 详细的进度反馈

---

## 🚀 快速开始

### 基本用法

```powershell
# 增量回填所有数据（推荐）
python .\scripts\backfill_aggregated_data.py
```

这将：
- 处理所有 6 个货币对（EURUSD, GBPUSD, USDJPY, AUDUSD, USDCAD, USDCHF）
- 生成所有 4 个时间周期（M5, M15, M30, H1）
- 只填补缺失的数据（不重复处理已有数据）

## 📖 详细用法

### 1. 指定货币对

```powershell
# 只回填 EURUSD
python .\scripts\backfill_aggregated_data.py --symbols EURUSD

# 回填多个货币对
python .\scripts\backfill_aggregated_data.py --symbols EURUSD GBPUSD USDJPY
```

### 2. 指定时间周期

```powershell
# 只回填 M5 数据
python .\scripts\backfill_aggregated_data.py --timeframes M5

# 回填 M5 和 M15
python .\scripts\backfill_aggregated_data.py --timeframes M5 M15

# 回填所有时间周期
python .\scripts\backfill_aggregated_data.py --timeframes M5 M15 M30 H1
```

### 3. 指定时间段

```powershell
# 回填 2024 年的数据
python .\scripts\backfill_aggregated_data.py --start-date "2024-01-01" --end-date "2024-12-31"

# 回填指定月份
python .\scripts\backfill_aggregated_data.py --start-date "2024-10-01" --end-date "2024-10-31"

# 回填最近 7 天
python .\scripts\backfill_aggregated_data.py --start-date "2025-10-03" --end-date "2025-10-10"
```

### 4. 全量回填模式

```powershell
# 全量回填（删除现有数据并重新聚合）
python .\scripts\backfill_aggregated_data.py --full

# 全量回填特定货币对和时间周期
python .\scripts\backfill_aggregated_data.py --symbols EURUSD --timeframes M5 --full
```

⚠️ **注意**：全量模式会删除现有数据，请谨慎使用！

## 🎯 常见场景

### 场景 1：首次设置（回填所有历史数据）

```powershell
# 一次性回填所有历史数据
python .\scripts\backfill_aggregated_data.py
```

### 场景 2：每日更新（只填补新数据）

```powershell
# 增量回填（默认模式）
python .\scripts\backfill_aggregated_data.py

# 或指定最近几天
python .\scripts\backfill_aggregated_data.py --start-date "2025-10-08"
```

### 场景 3：修复特定时间段的数据

```powershell
# 重新聚合 2024 年 5 月的数据
python .\scripts\backfill_aggregated_data.py \
    --start-date "2024-05-01" \
    --end-date "2024-05-31" \
    --full
```

### 场景 4：只处理单个货币对的单个时间周期

```powershell
# 只回填 EURUSD 的 M5 数据
python .\scripts\backfill_aggregated_data.py --symbols EURUSD --timeframes M5
```

### 场景 5：批量回填多个货币对

```powershell
# 回填主要货币对的 M5 和 M15
python .\scripts\backfill_aggregated_data.py \
    --symbols EURUSD GBPUSD USDJPY \
    --timeframes M5 M15
```

## 🔧 参数说明

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `--symbols` | 货币对列表 | 所有 | `--symbols EURUSD GBPUSD` |
| `--timeframes` | 时间周期列表 | 所有 | `--timeframes M5 M15` |
| `--start-date` | 开始日期 | M1数据最早日期 | `--start-date "2024-01-01"` |
| `--end-date` | 结束日期 | M1数据最晚日期 | `--end-date "2024-12-31"` |
| `--full` | 全量回填模式 | 增量模式 | `--full` |
| `--config` | 配置文件路径 | config/clickhouse_config.json | `--config my_config.json` |

### 支持的货币对

- `EURUSD` - 欧元/美元
- `GBPUSD` - 英镑/美元
- `USDJPY` - 美元/日元
- `AUDUSD` - 澳元/美元
- `USDCAD` - 美元/加元
- `USDCHF` - 美元/瑞郎

### 支持的时间周期

- `M5` - 5分钟
- `M15` - 15分钟
- `M30` - 30分钟
- `H1` - 1小时

## 🎓 聚合规则

从 M1 数据聚合到其他时间周期时，使用以下规则：

| 字段 | 聚合方法 | 说明 |
|------|----------|------|
| **symbol** | 分组键 | 货币对标识 |
| **timestamp** | 时间窗口对齐 | 对齐到时间窗口开始时间 |
| **open** | anyLast() | 时间窗口内任意 open 值 |
| **high** | max() | 时间窗口内最高价 |
| **low** | min() | 时间窗口内最低价 |
| **close** | anyLast() | 时间窗口内任意 close 值 |
| **volume** | sum() | 时间窗口内成交量总和 |

### 示例

假设有以下 M1 数据（10:00-10:04）：

| timestamp | open | high | low | close | volume |
|-----------|------|------|-----|-------|--------|
| 10:00 | 1.1000 | 1.1005 | 1.0995 | 1.1003 | 100 |
| 10:01 | 1.1003 | 1.1008 | 1.1000 | 1.1007 | 150 |
| 10:02 | 1.1007 | 1.1010 | 1.1005 | 1.1009 | 120 |
| 10:03 | 1.1009 | 1.1012 | 1.1007 | 1.1010 | 130 |
| 10:04 | 1.1010 | 1.1015 | 1.1008 | 1.1012 | 140 |

聚合为 M5 数据：

| timestamp | open | high | low | close | volume |
|-----------|------|------|-----|-------|--------|
| 10:00 | 1.1000 | 1.1015 | 1.0995 | 1.1012 | 640 |

## ⚠️ 注意事项

### 1. 增量 vs 全量模式

| 模式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **增量**（默认） | 快速、不重复处理 | 不修复已有错误数据 | 日常更新、首次回填 |
| **全量**（--full） | 确保数据准确 | 耗时长、删除现有数据 | 修复数据、重新计算 |

### 2. 性能优化

- **批量处理**: 一次处理多个货币对和时间周期比多次运行单个更高效
- **时间段**: 合理划分时间段，避免一次处理过长时间范围
- **并发**: 如需加速，可以分别运行多个实例处理不同货币对

### 3. 数据一致性

- 确保 M1 源数据完整且正确
- 全量回填前建议备份数据
- 增量回填不会修复已有的错误数据

## 🔄 与物化视图的关系

**重要**：本脚本用于**历史数据回填**，而物化视图用于**新数据自动聚合**。

### 使用场景对比

| 场景 | 使用工具 | 说明 |
|------|----------|------|
| 设置物化视图后，插入新 M1 数据 | 物化视图 | 自动聚合，无需手动操作 |
| 物化视图设置前的历史数据 | 本脚本 | 一次性回填历史数据 |
| 修复错误的聚合数据 | 本脚本 | 使用 `--full` 模式重新聚合 |
| 物化视图失效期间的数据 | 本脚本 | 增量回填缺失数据 |

### 推荐工作流程

1. **首次设置**：
   ```powershell
   # 1. 设置物化视图
   python .\scripts\setup_clickhouse_materialized_views.py
   
   # 2. 回填历史数据
   python .\scripts\backfill_aggregated_data.py
   ```

2. **日常使用**：
   - 插入新 M1 数据 → 物化视图自动聚合
   - 无需运行回填脚本

3. **数据修复**：
   ```powershell
   # 重新聚合特定时间段
   python .\scripts\backfill_aggregated_data.py \
       --start-date "2024-05-01" \
       --end-date "2024-05-31" \
       --full
   ```

## 🛠️ 故障排查

### 问题 1：连接失败

**错误**: `❌ 连接失败: Connection refused`

**解决**:
- 检查 ClickHouse 服务是否运行
- 验证 `config/clickhouse_config.json` 配置正确
- 检查网络连接和防火墙

### 问题 2：源数据不存在

**输出**: `⚠️  源数据不存在`

**解决**:
```powershell
# 先导入 M1 数据
python .\scripts\fxcm_importer.py --timeframe M1
```

### 问题 3：插入失败

**错误**: `❌ 失败: ...`

**解决**:
- 查看日志文件获取详细错误信息
- 检查目标表是否存在
- 验证数据库权限

### 问题 4：性能慢

**现象**: 回填速度很慢

**优化**:
- 减小时间范围，分批处理
- 单独处理每个货币对
- 在低峰期运行
- 检查 ClickHouse 服务器性能
