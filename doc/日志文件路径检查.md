## 📂 路径说明

所有脚本都使用相同的路径模式：
```python
Path(__file__).parent.parent / 'logs'
```

- `__file__`: 当前脚本文件路径（在 scripts/ 目录下）
- `.parent`: 第一个 parent 指向 scripts/ 目录
- `.parent.parent`: 第二个 parent 指向 Forex/ 根目录
- `/ 'logs'`: 拼接 logs 子目录
