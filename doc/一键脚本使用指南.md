## 🚀 一、一键导入所有数据

### 功能说明

自动扫描`fxcm_data`文件夹中的所有CSV文件，并导入到ClickHouse数据库。

**包含的数据：**
- 所有货币对的M1分钟线数据（AUDUSD/EURUSD/GBPUSD/USDJPY/USDCAD/USDCHF）
- 所有货币对的D1日线数据

### 使用方法

```bash
python 一键导入所有数据.py
```

### 运行流程

1. **读取配置** - 自动读取`config/clickhouse_config.json`
2. **扫描文件** - 扫描所有待导入的CSV文件
3. **确认导入** - 显示文件统计，等待用户确认
4. **导入D1数据** - 先导入所有D1日线数据
5. **导入M1数据** - 再导入所有M1分钟线数据
6. **生成报告** - 显示详细的导入统计

## 🔍 二、一键验证所有数据

### 功能说明

全面验证ClickHouse数据库中的数据质量、完整性和一致性。

**检查项目：**
1. ✅ 基础统计信息（表大小、记录数、货币对数）
2. ✅ 货币对覆盖情况（M1和D1数据的时间范围）
3. ✅ 数据质量检查（价格异常、OHLC逻辑）
4. ✅ 物化视图状态（聚合数据生成情况）
5. ✅ 数据一致性（M1与聚合数据的比例验证）

### 使用方法

```bash
python 一键验证所有数据.py
```

### 运行流程

1. **连接数据库** - 连接到ClickHouse
2. **基础统计** - 检查所有表的记录数和大小
3. **覆盖检查** - 验证每个货币对的数据范围
4. **质量检查** - 检测价格异常和逻辑错误
5. **视图检查** - 验证物化视图是否正常工作
6. **一致性检查** - 验证M1与聚合数据的一致性
7. **生成报告** - 输出综合评分和建议

## 📋 三、常见问题

### Q1: 导入时提示"连接失败"怎么办？

**原因：** ClickHouse服务器未启动或网络不通

**解决：**
1. 检查ClickHouse服务器是否运行
2. 检查`config/clickhouse_config.json`中的配置
3. 测试网络连接：`ping 192.168.2.168`

### Q2: 导入很慢怎么办？

**原因：** 
- 网络延迟高
- 服务器性能不足
- 大量数据需要查重

**优化建议：**
1. 使用有线网络而非无线
2. 升级ClickHouse服务器配置
3. 首次导入时数据库为空，速度最快
4. 关闭其他占用网络/CPU的程序

### Q3: 某个文件导入失败怎么办？

**处理：**
1. 查看错误信息（脚本会打印详细错误）
2. 检查CSV文件格式是否正确
3. 手动使用`import_fxcm_to_clickhouse.py`导入单个文件
4. 其他文件不受影响，会继续导入

### Q4: 导入中断了，能继续吗？

**可以！** 脚本支持断点续传：
- 已导入的数据会被自动跳过
- 直接重新运行导入脚本即可
- 不会产生重复数据

### Q5: 验证发现问题怎么办？

**根据问题类型：**

| 问题类型 | 解决方法 |
|---------|---------|
| 数据缺失 | 运行导入脚本补充数据 |
| 价格异常 | 检查CSV源文件，重新导入 |
| OHLC逻辑错误 | 检查CSV源文件质量 |
| 一致性问题 | 删除聚合表，让物化视图重新生成 |

### Q6: 如何删除所有数据重新导入？

```sql
-- 在ClickHouse中执行
DROP TABLE IF EXISTS forex_data.ohlcv_m1;
DROP TABLE IF EXISTS forex_data.ohlcv_d1;
DROP TABLE IF EXISTS forex_data.ohlcv_m5;
DROP TABLE IF EXISTS forex_data.ohlcv_m15;
DROP TABLE IF EXISTS forex_data.ohlcv_m30;
DROP TABLE IF EXISTS forex_data.ohlcv_h1;
DROP VIEW IF EXISTS forex_data.ohlcv_m5_mv;
DROP VIEW IF EXISTS forex_data.ohlcv_m15_mv;
DROP VIEW IF EXISTS forex_data.ohlcv_m30_mv;
DROP VIEW IF EXISTS forex_data.ohlcv_h1_mv;
```

然后运行：
```bash
python scripts\create_clickhouse_tables.py
python 一键导入所有数据.py
```

## 🎯 四、使用流程建议

### 首次使用

```
1. 准备数据
   └─ 确保fxcm_data文件夹中有CSV文件

2. 创建表结构
   └─ python scripts\create_clickhouse_tables.py

3. 导入数据
   └─ python 一键导入所有数据.py

4. 验证数据
   └─ python 一键验证所有数据.py

5. 开始使用
   └─ python scripts\query_examples.py
```

### 日常使用

```
1. 定期验证
   └─ python 一键验证所有数据.py

2. 补充新数据
   └─ 添加新CSV到fxcm_data文件夹
   └─ python 一键导入所有数据.py（自动跳过已有数据）

3. 数据查询
   └─ python scripts\query_examples.py
   └─ 或使用自己的查询脚本
```
