# FXCM数据导入ClickHouse使用指南

## 📊 功能概述

`import_fxcm_to_clickhouse.py` 是一个功能完善的数据导入工具，用于将FXCM的CSV历史数据导入到ClickHouse数据库。

### ✨ 核心功能

1. **批量导入** - 自动扫描并导入所有M1和D1数据
2. **智能查重** - 自动检测已存在的数据
3. **数据对比** - 发现数据冲突时对比新旧数据
4. **冲突处理** - 提供多种冲突解决策略
5. **断点续传** - 支持中断后继续导入
6. **详细日志** - 记录导入过程和统计信息

## 🔍 数据查重机制

### 查重流程

```
读取CSV文件
    ↓
提取时间范围（start_time, end_time）
    ↓
查询数据库：该时间范围内是否已有数据？
    ↓
┌─────────────────┴─────────────────┐
│                                   │
NO（新数据）                    YES（可能重复）
│                                   │
批量插入 ✅                       逐行对比
                                    ↓
                        ┌───────────┴───────────┐
                        │                       │
                    数据一致               数据冲突
                        │                       │
                    跳过 ⏭️                   询问处理
                                                ↓
                                    ┌───────────┴───────────┐
                                    │                       │
                                覆盖 🔄                  跳过 ⏭️
                                    │                       │
                            删除旧数据 + 插入新数据      保留旧数据
```

### 数据对比精度

- 使用 **5位小数精度** 比较OHLC数据
- 容差：`1e-5`（0.00001）
- 避免浮点数误差导致的误判

## ⚠️ 冲突处理策略

### 场景：数据不一致

```
⚠️  数据冲突：EURUSD @ 2015-01-04 22:00:00
   旧数据 OHLC: (1.19552, 1.19552, 1.19355, 1.19404)
   新数据 OHLC: (1.19553, 1.19553, 1.19356, 1.19405)
   
   选择操作 [s]跳过 / [o]覆盖 / [a]全部跳过 / [A]全部覆盖:
```

### 选项说明

| 选项 | 说明 | 适用场景 |
|------|------|---------|
| `s` | 跳过此条，保留旧数据 | 相信数据库中的数据更准确 |
| `o` | 覆盖此条，使用新数据 | 相信CSV文件中的数据更准确 |
| `a` | 全部跳过（后续不再询问） | 批量导入时，全部保留旧数据 |
| `A` | 全部覆盖（后续不再询问） | 批量导入时，全部使用新数据 |

### 推荐策略

**首次导入**: 选择 `A`（全部覆盖）  
**增量更新**: 选择 `a`（全部跳过）  
**数据修复**: 选择 `o`（逐条判断）

## 🔧 技术细节

### CSV字段映射

| CSV字段 | 数据库字段 | 处理方式 |
|---------|-----------|---------|
| (无) | `symbol` | 从文件路径提取（如"EURUSD"） |
| `DateTime` | `timestamp`/`date` | 直接映射 |
| `Open` | `open` | 直接映射 |
| `High` | `high` | 直接映射 |
| `Low` | `low` | 直接映射 |
| `Close` | `close` | 直接映射 |
| (无) | `volume` | 自动填充0（DEFAULT） |
| (无) | `created_at` | 自动生成（DEFAULT now()） |

### 批量插入优化

- 使用ClickHouse的 `FORMAT CSV` 批量插入
- 每个文件作为一个批次
- M1数据：每周约10,080条（7天×24小时×60分钟）
- D1数据：每年365条

### 删除机制（覆盖时）

使用 `ALTER TABLE ... DELETE` 语句：
```sql
ALTER TABLE forex_data.ohlcv_m1
DELETE WHERE symbol = 'EURUSD'
  AND timestamp IN ('2015-01-04 22:00:00', ...)
```

## 🐛 常见问题

### 1. 导入速度慢

**原因**: 查重需要查询数据库  
**解决**: 首次导入时，数据库为空，速度很快

### 2. 连接超时

**原因**: ClickHouse服务器繁忙或网络问题  
**解决**: 增加超时时间（脚本中已设为300秒）

### 3. 内存不足

**原因**: 单个CSV文件太大  
**解决**: 脚本已优化，逐文件处理，内存占用小

### 4. 数据冲突太多

**原因**: CSV文件已更新，但数据库中有旧数据  
**解决**: 选择 `A`（全部覆盖）策略
